EdTechRAG Suche – Embed

Ein Script, zwei Betriebsarten. Die Box gehört auf jede Seite und navigiert zur Suchseite; die Ergebnisdarstellung liest ?q= aus der Adresse.

Einbau

<!-- Box, z. B. im Kopfbereich jeder Seite -->
<div
  class="at-ed-tech-edtechrag-search"
  hidden="hidden"
  data-embed-id="telucation.tugraz.at"
  data-mode="box"
  data-results-url="/suche/"
  data-lang="de"
  data-edtechrag-base-url="https://e-flaait.tugraz.at/edtechrag/"
></div>

<!-- Ergebnisdarstellung, auf der Suchseite -->
<div
  class="at-ed-tech-edtechrag-search"
  hidden="hidden"
  data-embed-id="telucation.tugraz.at"
  data-mode="results"
  data-lang="de"
  data-limit="10"
  data-ai-overview="optin"
  data-userterms-url="https://e-flaait.tugraz.at/edtechrag/benutzerbedingungen"
  data-userterms-duration="12"
  data-edtechrag-base-url="https://e-flaait.tugraz.at/edtechrag/"
></div>

<link rel="stylesheet" href="https://e-flaait.tugraz.at/edtechrag/embed/search/edtechrag-search.css">
<script src="https://e-flaait.tugraz.at/edtechrag/embed/search/edtechrag-search.js"></script>
<noscript><p>Die Suche braucht JavaScript.</p></noscript>

Attribute

data-embed-id die EdTechRAG-Repository-URL. Pflicht.
data-mode box (Standard) oder results
data-results-url Ziel der Box. Ohne sie tut die Box nichts.
data-query-param Name des Suchparameters, Standard q
data-lang de / en. Ohne Angabe zählt das lang der Seite.
data-limit höchstens so viele Treffer; darüber entscheidet aber das Repository.
data-ai-overview optin (Standard) oder off für diese Seite
data-userterms-url, data-userterms-duration Bedingungen und Gültigkeit in Monaten (Standard 12)
data-design tugraz oder tc

Styles überschreiben

Alles, was man vernünftigerweise umstellen will, ist eine Custom Property auf dem Host-Element. Überschreiben heißt: dieselbe Variable neu deklarieren – kein !important, kein Wettrennen um Selektoren. 

.at-ed-tech-edtechrag-src-host {
  --at-ed-tech-edtechrag-src-accent: var(--brand);
  --at-ed-tech-edtechrag-src-radius: 0;
}

Der AI-Overview

Die Treffer erscheinen sofort. Der Overview darüber zeigt zuerst nur die Zustimmung: Hinweis, Link zu den Bedingungen, ein Knopf. Erst danach wird er gestreamt – zeichenweise, nicht am Ende auf einmal. Über die drei Punkte neben der Überschrift lässt sich die Zustimmung widerrufen; die Suche selbst läuft weiter. Gespeichert wird sie unter edtechrag-search-overview-<embedId> im localStorage – ein eigener Schlüssel, damit Chat- und Suchzustimmung getrennt bleiben.

Ob es einen Overview überhaupt gibt, entscheidet /admin/repositories/<url> (Abschnitt „AI overview"). Ist er dort aus, meldet die Suche das mit, und das Widget zeigt keine Zustimmung für etwas, das es nicht gibt.

Live

Zwei Abweichungen gegenüber dem Snippet, damit diese Seite lokal funktioniert: data-edtechrag-base-url zeigt auf denselben Host, und die Assets werden relativ geladen. data-embed-id muss eine Repository-URL sein, für die Enable search API gesetzt ist und deren Allowed embed host regex auf localhost passt.
